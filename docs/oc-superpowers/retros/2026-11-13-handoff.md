## What 5.6.2 is

The stable 5.5.0 media architecture with the live-toggle UX kept: `seen`
registration, a passive hook on seen-but-off hosts, live START/STOP with the
session kept, automatic one-time reload on a host's first-ever enable. No live
amplitude probe, no per-source re-tap, no churn watchdog — those were the
instability.

## Residual

- Cross-origin media without CORS approval, DRM/EME media and `srcObject`
  streams are not routed, exactly as in 5.5.0: they play native — or silent if
  the page's own graph takes them. No live probe; exclusion is the remedy.
- If a target site needs normalization of protected media, the next slice is a
  CORS upgrade (DNR + element reload) or a tabCapture/offscreen path, with the
  capture-indicator cost. Do not reintroduce an unproven per-source live tap.
- The `setVolume`-unmute settle and the measured YouTube facts live in
  `SYSTEM.md`; the player-actions retro is in `docs/oc-superpowers/retros/`.
