Crunchyroll Discord Presence

Local only. Nothing leaves this machine except the Discord IPC call.

1. Discord application

Presence works out of the box with the built-in Crunchyroll application. Save a different application ID only if you want your own application name and artwork in Discord.

  1. Open discord.com/developers/applications.
  2. Click New Application, name it, and create it.
  3. Copy the Application ID from the General Information page.

17 to 20 digits. Clear the field and save to switch back to the built-in application.
