Web Discord RPC

Local only. Nothing leaves this machine except the Discord call.

1. Discord application

Presence works out of the box with the built-in application. Save your own application ID only if you want your own name and artwork in Discord.

17 to 20 digits. Clear the field and save to go back to the built-in application.

2. Connection

Automatic uses the Discord desktop app's local socket first and falls back to arRPC. A forced mode never falls back.

Off stops the native host entirely. Nothing is published while it is off.

4. Native host

Run this once from the extension folder, with Node 22 or newer:

node scripts/install-host.mjs

Verify the host files and registry entries without writing anything:

node scripts/install-host.mjs --check
