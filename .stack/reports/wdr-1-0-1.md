## Lesson

A version seam in this repo is a four-file transaction, not a manifest edit: `verify-integration`
compares the README row against *both* the manifest and `package.json`, so bumping the two JSON files
first and running the check turns a string change into a check that fails by name before the docs
move — do that deliberately, then close it. Note also that the two README predicates look redundant
but are not: one pins the cell to the manifest, the other only asks that the README mention
`package.json`'s version somewhere, so a stale cell in a second row would pass the second and fail
the first.
