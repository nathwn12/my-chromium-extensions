## Lesson

The lockfile is the last place a version hides: `manifest.json` and `package.json` move together by habit, but the lock only updates when someone runs `npm install`, so a package can be three releases ahead of what `package-lock.json` claims for months. The cheap move is a one-liner that compares every `packages/*` lock entry to its manifest — that comparison is the only thing that turns the staleness into a visible number, because `verify-integration.mjs` checks the README against the manifest but never against the lock. And the red proof cost one command: bump the JSON first, watch the check fail by the exact stale string ("README 1.0.2 vs manifest 1.0.3"), then let the prose edits turn it green. Doing the reverse order leaves you guessing whether the check was ever able to see the change.
